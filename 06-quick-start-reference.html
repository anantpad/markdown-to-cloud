6.10 Troubleshooting Quick Reference

Problem First thing to check
quarto: command not found Is Quarto installed in WSL?
Git push fails git status, remote URL, authentication
Book doesn’t render Run quarto render and read the first error
Image doesn’t appear Check relative path/case
GitHub Pages not updating Check GitHub Actions
VS Code editing wrong environment Confirm WSL: Ubuntu
Changes aren’t being pushed git status

6.11 The 5-Minute Cheat Sheet

# Clone
git clone <repo-url>
cd <repo>

# Create Quarto book
quarto create-project . --type book

# Get into your project
cd ~/projects/my-book

# Preview
quarto preview

# Verify the complete book
quarto render

# Save changes
git add .
git commit -m "Update book"
git push

# Publish the book
quarto publish

Quarto will guide you through the publishing destination the first time
